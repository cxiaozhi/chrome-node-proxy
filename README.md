# Clash 浏览器代理

关闭 Clash 系统代理时，也能让 Chrome 使用本机 Clash 当前选中的代理线路。只需要保持 Clash 运行，并开放默认的 HTTP 或 Mixed 代理端口 `127.0.0.1:7890`。Windows 系统代理可以保持关闭。

1. 在 `chrome://extensions` 开启开发者模式，加载仓库的 `extension` 目录。之前已加载的扩展可以直接点重新加载。
2. 点击 Chrome 工具栏里的「Clash 浏览器代理」，打开「启用 Clash 浏览器代理」开关。关闭开关时 Chrome 恢复直连。

订阅、选节点和测速在 Clash 中完成。
